## 2. 架構決策紀錄 (Architecture Decision Records, ADR)

### ADR 001: 純前端高互動性單頁面應用 (SPA)
* **狀態：** 已核准 (Approved)
* **脈絡：** 懷恩堂會友與長輩需要加載快速、無須繁複登入、且能在手機或平板上直覺瀏覽的互動網頁。
* **決定：** 採用 Vanilla HTML、CSS、與 JavaScript 進行開發，不引入第三方重型框架（如 React/Vue）。
* **影響：** 
  * 載入速度極快，符合長輩友善（Senior-Friendly）與低網路頻寬環境。
  * 零伺服器負擔，可直接透過 GitHub Pages 進行靜態部署。

### ADR 002: 基於 HTML5 Canvas 的專屬通行證生成與下載
* **狀態：** 已核准 (Approved)
* **脈絡：** 為了提升參與感，網頁需要提供會友專屬的立約圖誌（通行證），並支援下載分享。
* **決定：** 使用 HTML5 Canvas 於客戶端動態渲染 1000x600 高畫質雙色調立約卡片，並結合 `toDataURL` 提供無伺服器端的 PNG 圖片下載。
* **影響：** 
  * 完全保護隱私（姓名與專業不傳送至後端伺服器），符合資安與隱私規範。
  * 卡片具備高解析度，適合在社群軟體（LINE、微信）傳播與分享。

### ADR 003: 基於 IntersectionObserver 的沉浸式滾動淡入機制
* **狀態：** 已核准 (Approved)
* **脈絡：** 使用者希望「思考」與「結語」等問題能隨著 scroll 緩緩浮出，給予讀者心靈沉澱與默想的氛圍。
* **決定：** 使用瀏覽器原生 `IntersectionObserver` 監聽 `.scroll-reveal` 類別，並搭配 `data-delay` 實現多級延遲交錯淡入（Staggered Fade-in）。
* **影響：** 
  * 效能極佳，免去 scroll 事件頻繁監聽所導致的瀏覽器卡頓（Reflow/Repaint）。
  * 動畫表現流暢（2 秒立體淡入與微幅上移），營造出沉浸式的信仰反思體驗。
